# TrafficSign-AI

## Traffic Sign Classification and Detection Web Application

TrafficSign-AI is an AI-based web application for traffic sign recognition using a CNN classification model and YOLO object detection.

### Technologies Used

- Python
- Flask
- TensorFlow / Keras
- YOLO
- ONNX Runtime
- OpenCV
- HTML
- CSS
- JavaScript

### Main Features

- Traffic sign image upload
- Traffic sign classification
- Traffic sign object detection
- Live camera detection
- Prediction confidence
- Prediction history
- Dashboard and analytics
- Dark / light theme

### Models

- CNN model: `traffic_sign_model.keras`
- YOLO model: `best.onnx`
- Class mapping: `Classes.json`
