How It Works

Four simple steps from image to prediction.

Upload or Scan

Select an image or use the live camera to scan a traffic sign.

02

Object Detection

YOLO detects the traffic sign and identifies its location in the image.

03

04

Prediction

The predicted class, confidence and detection box are displayed.

ABOUT THE PROJECT

Traffic Sign Classification Using Machine Learning

TrafficSign AI is a machine-learning based traffic sign classification system developed using a Convolutional Neural Network. The system is trained to classify traffic signs into 43 different classes and uses YOLO-based object detection for live traffic sign localization.
